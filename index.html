Why we built this.

Spotlight searches filenames. Your memory doesn't work that way.

You remember the topic. The class it was for. A phrase that was somewhere inside it. The month you wrote it. Found It! takes all of that and surfaces the right file — with a reason it matched, not just 200 results and a prayer.

It runs in your menu bar. It indexes everything locally. Nothing leaves your Mac for core search. Press ⌘⇧O from any app, type what you remember, and you're done.

We built this because we kept opening folder after folder for a file we saved five minutes ago. Spotlight wasn't the answer. This is.

Questions.

Does it upload my files?
No. Core search is local-first — file contents stay on your Mac. Optional cloud features, if they ever ship, will be clearly described and opt-in.
Is this better than Spotlight?
Spotlight is filename-first. Found It! searches by meaning and contents — it understands "math homework from last week" and returns ranked results with reasons for each match.
What file types does it support?
PDFs, Office files, notes, markdown, images with text (via OCR), code files, and more. The indexer reads text content, metadata, and runs OCR on images.
What happens after the free limit?
You wait for the daily reset, or upgrade to Pro for unlimited searches. Free users keep full indexing and Browse/Archive features.
Windows or iOS?
macOS only for now. Found It! integrates tightly with macOS file APIs and the menu bar. iOS is on the roadmap.
