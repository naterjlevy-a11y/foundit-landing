How it works

It indexes first, then searches fast.

Found It builds a local index of your files in the background. When you search, everything is already there — no scanning, no waiting.

01

Found It indexes your files

Scans Documents, Downloads, and Desktop — building a local SQLite index with AI-generated summaries, embeddings, and smart metadata.

local folders AI summaries SQLite
02

Smart keyword extraction

Your query is lemmatized (e.g. "running" → "run"), expanded with synonyms, and used to fetch candidates from the local index via fast LIKE queries.

NLTagger lemmatization local only
03

Scored, ranked, and ready

Each candidate file is scored against your query across 10+ signals — filename, content, metadata, embeddings, recency, and date — then ranked and shown instantly.

exact / lemma / fuzzy embeddings ranked results

Questions.

Is there a free version?
Yes. Free includes unlimited searches across your first 500 indexed files. No credit card required to download.
How fast is the search?
Standard search is fully local — keyword extraction, scoring, and ranking all happen on your Mac with no network call. Results appear in milliseconds. Deep Search (Pro) adds an AI pass which takes 1–3 seconds but finds much more for vague or messy queries.
What does Pro unlock?
Pro unlocks unlimited file indexing, Deep Search (AI query expansion + reranking + natural-language answer), image conversion for common formats, drag-and-drop import and use, and priority re-indexing.
How does Found It score search results?
Each candidate file is scored across 10+ signals: exact keyword match, lemma match (e.g. "running" matches "run"), fuzzy match for typos, filename match, metadata topics and entities, content chunks, embedding cosine similarity, document type, date window, and recency. Higher scores float to the top.
Where are my auth credentials stored?
Auth tokens are stored in the macOS Keychain with device-only access — not in a file on disk. API keys are protected server-side through Supabase Edge Functions and are never bundled in the app binary.
What folders does Found It index?
Found It indexes common Mac locations — Documents, Downloads, and Desktop. Support for additional custom folders is on the roadmap.
How much does Pro cost?
Pro is $10.99/month and unlocks unlimited indexing, Deep Search, image conversion, drag-and-drop import and use, and priority re-indexing. Cancel anytime through the billing portal.
Does Found It replace Spotlight?
No. Spotlight is great when you know what something is called. Found It is for when you remember what the file was about — the topic, the class, the project — not its exact name.
Does search happen online?
Standard search is 100% local — no network call of any kind. Deep Search (Pro) uses a lightweight query expansion call through a secure Edge Function to understand intent and find related terms. This call costs under $0.001 and the API key is never exposed in the app.
